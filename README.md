# Creative Visuals 🌸

> **Creative Visuals** is a premium creative marketing agency landing page combining classical Japanese calligraphy aesthetic (Edo-inspired ink wash) with state-of-the-art interactive web motion design.

---

## ✨ Features

- **Artistic Hero Stage**: 3D perspective stage with mouse-tracking parallax depth and dynamic entrance typography.
- **Interactive Falling Petals**: High-performance HTML5 Canvas sakura/cherry blossom particle physics simulation.
- **Interactive 3D Carousel**: Drag, swipe, and arrow-key controllable rotating 3D portfolio showcase.
- **Detailed Project Viewer**: Built-in modal viewer with keyboard navigation (`Esc`, `ArrowLeft`, `ArrowRight`, `Tab` focus trap) and video/image support.
- **Interactive 3D Cards**: Tilt-reactive cards with dynamic specular light reflection following the cursor.
- **Custom Ink Cursor**: Magnetic smooth trailing cursor on fine-pointer devices.
- **Mobile Responsive**: Custom drawer navigation, touch gestures, and adaptive layout for all screen sizes.
- **Zero Build Step**: Fully self-contained pure HTML, CSS, and Vanilla JavaScript with embedded assets.
